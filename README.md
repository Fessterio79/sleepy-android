# Sleepy 2.0 — Android alarm & sleep journal

Sleepy — приложение-будильник для Android на Kotlin и Jetpack Compose.

## Что есть в версии 2.0
- несколько будильников, создание, редактирование, удаление и включение/выключение;
- удобный системный выбор времени;
- однократное срабатывание или повтор по выбранным дням недели;
- стандартный сигнал, локальный аудиофайл или интернет-радио по URL;
- повторный сигнал (snooze) с настраиваемой задержкой;
- вибрация и плавное нарастание громкости;
- резервный стандартный сигнал при ошибке воспроизведения выбранного источника;
- ручной журнал сна: начало, пробуждение, история и средняя продолжительность;
- настройки вибрации, повтора и нарастания громкости;
- восстановление будильников после перезагрузки и изменения времени.

## Сборка
После push в main GitHub Actions собирает debug APK.
Открой Actions → последний успешный запуск → Artifacts → sleepy-debug-apk.

Минимальная версия Android: 10 (API 29). Для точного срабатывания нужно разрешить Sleepy точные будильники в настройках Android.

## Важно
Журнал сна заполняется вручную и не определяет фазы сна. Радио требует интернет-соединения. Это debug-сборка для личного тестирования; перед широкой публикацией необходимы тестирование на устройствах, release-подпись и проверка поведения в энергосберегающих режимах.
