# Sleepy 1.2 — Android alarm app

Текущая версия проекта: **1.2**.

Ранний MVP приложения-будильника на Kotlin + Jetpack Compose.

## Возможности
- несколько будильников и повтор по дням недели;
- точное планирование через AlarmManager;
- выбор локального аудиофайла;
- потоковое радио по URL;
- экран срабатывания и базовая статистика сна;
- восстановление будильников после перезагрузки.

## Сборка APK
После push в main GitHub Actions автоматически собирает debug APK.
Готовый файл будет доступен во вкладке Actions → последний успешный запуск → Artifacts.

Минимальная версия Android: 10 (API 29). Для точных будильников нужно разрешить Sleepy соответствующее разрешение в настройках Android.

Это ранний MVP: snooze, плавное нарастание громкости, автоматический журнал сна и резервное переключение радио ещё требуют реализации и тестирования.
